# GIF Gallery Search - React App

A modern, responsive React application that allows users to search for GIFs, view trending animations, and save their favorites for quick access later. 

**Live Demo:** [https://gif-gallery-app-ashishaugustine.netlify.app/](https://gif-gallery-app-ashishaugustine.netlify.app/)

---

## 🌟 Features

*   **Discover Trending GIFs:** Instantly view popular and trending GIFs on the homepage.
*   **Search Functionality:** Quickly find specific GIFs using the search bar (e.g., "run", "dance", "cat").
*   **Save Favorites:** Like your favorite GIFs and access them all in a dedicated "Favorites" tab.
*   **Responsive UI:** Clean, intuitive interface that looks great on all devices.

---

## 💻 Technologies Used

This project is built with a modern frontend stack:

*   **[React](https://react.dev/)** - UI Library
*   **[Vite](https://vitejs.dev/)** - Build Tool & Development Server
*   **[TypeScript](https://www.typescriptlang.org/)** - Static Typing
*   **[Tailwind CSS](https://tailwindcss.com/)** - Utility-First Styling
*   **[shadcn/ui](https://ui.shadcn.com/)** - Accessible and customizable UI components

## 🚀 Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/ashish-augustine/gif-gallery-favorites-app.git](https://github.com/ashish-augustine/gif-gallery-favorites-app.git)
    cd gif-gallery-favorites-app
    ```

2.  **Install the necessary dependencies:**
    ```bash
    npm i
    ```

3.  **Start the development server:**
    This will start the app with auto-reloading and an instant preview.
    ```bash
    npm run dev
    ```

4.  **Open the app:**
    Open your browser and navigate to the local URL provided in your terminal (usually `http://localhost:5173`).
